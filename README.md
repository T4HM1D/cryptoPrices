# Crypto Price Fetcher

A Python script that fetches cryptocurrency exchange rates from CoinGecko and saves them to individual CSV files.

## Prerequisites

Install the required dependencies:

```bash
pip install requests pandas python-dotenv
```

# Setup

Create a `.env` file in the project directory and add your CoinGecko API key:

```code
API_KEY= coingecko_api_key
```

# Usage

```bash
python crypto_prices.py
```
